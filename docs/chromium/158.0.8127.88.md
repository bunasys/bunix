**Reviewed 2026-11-25: clean, Hudhud moves to 158.0.8127.88** (on
ungoogled-chromium 158.0.8127.88-1, whose patches all apply), with Hudhud's
port to Nix (docs/browser.md).  The full report is 68,000 lines, almost all
of it the list of removed files; this is its summary and what was read.

- **Uncovered Google addresses (378 files):** none in code the Linux browser
  runs.  284 are documentation, tests, `agents/` notes for Chromium's own
  developers, OWNERS and metadata.  Of the other 94: Android Java, CI
  configuration (`infra/`, `.github/`, `DEPS`, `.gitmodules`), crates'
  Cargo.toml, and comments in code (protobuf and mojom definitions, Rust
  doc comments: `docs.google.com` design documents, `google.com` as an
  example in `omnibox_proto`, `type.googleapis.com` as a type URL's name
  in a comment).

  (`chrome_pgo_phase = 0`); 16 DevTools test screenshots; a picture in
  ml_drift's documentation; and `jxl`'s 32x32 dither table, data the JPEG
  XL decoder compiles in.
- **Removed files (66,125; the tarball is 991 MB, 157's was 2.0 GB):** the
  "lite" tarball leaves out more: webpagereplay's third-party code (23,007),
  depot_tools' and CPython's prebuilt programs, which ungoogled-chromium
  prunes anyway, test data (pdfium, headless, content, Skia's resources),
  the website's sources and DevTools' tests.  Whether anything the build
  needs went with them, the build says.
- **Commits:** not read: Chromium's log answered 503 at the time.  The
  release's security notes are Google's
  (chromereleases.googleblog.com), for 158.
